# Firm-by-firm: what is reported to be tested

Provenance: compiled 2026-10-15 from WebSearch results (prep-site guides, Glassdoor/1point3acres candidate reports, one LessWrong post).
Almost all are **third-party and candidate-reported; many prep sites sell products**. Formats change yearly and sources conflict
(e.g. Optiver "80 in 8" scoring is reported as -1 or -2 per wrong answer; SIG round counts range 3 to 11). Re-verify before relying.
Direct fetches of firm sites were blocked in the authoring session, so no firm-official page was read in full.

| Firm | Reported stages / content | Weight |
|---|---|---|
| Optiver | Timed online test: "80 in 8" mental arithmetic (80 questions, 8 min, wrong answers penalised); later probability/stats test, options theory, market-making sim, trading games, Zoom + onsite. | Speed first, then EV/options/market making |
| IMC | OA heavy on fast mental math and number sequences; trading game / options market-making sim; final interviews; coding element for traders. | Speed, pricing under pressure, some coding |
| Jane Street | Human-read applications (no automated OA reported by one source); probability + expected value in phone rounds; market-making game is the superday centrepiece. Official intro page: janestreet.com/probability-markets (probability, EV, making markets; not read in full). | Probability, EV, market making, reasoning aloud |
| SIG (Susquehanna) | OA of probability/logic questions (one report: 17 Q / 60 min); take-home data task reported; games round: market making on an uncertain value, AKQ betting game, Acey-Deucy poker. | EV, poker, game theory, decision science |
| Citadel Securities | OA (probability + mental math, older reports mention ML); technical phone screens (EV of asymmetric coin games, dice "expected rolls to get two 6s in a row"); onsite; project questions. | Probability/EV, stats, market intuition |
| DRW | ~45 min, ~6-problem math+probability OA for trader/research; then probability/brainteasers, trading intuition, market making; game theory examples (pirate game, AKQ, Penney's game). | Probability, game theory |
| HRT | OA, probability+brainteaser phone screen, programming phone screen, onsite. | Hard probability + real coding |
| Akuna / Flow Traders | Mental math + logical-reasoning / sequences tests; later brainteasers, market-making games, derivatives basics. | Speed, logic, basic derivatives |

## Role difference (trader vs researcher)
Trader loops: mental math, fast probability, market-making games, bet sizing; coding light-to-moderate.
Researcher loops: regression/inference/ML validation, take-home data challenge, solid Python. Firm type often matters more than title.
